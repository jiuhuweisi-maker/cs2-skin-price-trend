# CS 饰品 Skin Reveal 走势图

本地运行的 CS 饰品价格动画工作台。画面参考[这条抖音视频](https://www.douyin.com/video/7670634222289308978)：深色背景、红涨绿跌、滚动时间窗、线头金额、右上角实时收益，以及结尾的大金额定格。多件饰品时改用各线独立颜色和随动名称标签。

## 启动

在 Windows 上双击 [`启动.bat`](启动.bat)，浏览器会打开 `http://127.0.0.1:8765`。首次启动会创建 `.venv` 并安装 `requirements.txt`；需要 Python 3.11 以上。已存在 `.venv` 时直接启动。关闭批处理窗口或按 Ctrl+C 即可停止本地服务。程序只监听 `127.0.0.1`。

也可以手动执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

若 Windows 的 `python` 指向打不开的 Microsoft Store 别名，请安装正式 Python，或让启动脚本使用 Codex 捆绑的 Python。安装依赖时若临时目录无写入权限，可把 `TEMP`、`TMP` 指向本项目内的 `.tmp` 目录；`启动.bat` 已自动处理。

## 使用

1. 点击“加载两份演示数据”，验证播放和导出；数据是合成的，画面会注明“演示数据 · 非真实历史价”。
2. 输入一件饰品的中文或英文名称，点“联网搜索并读取”。例如 **蝴蝶刀传说** 或 `★ Butterfly Knife | Lore`，完整匹配会自动打开 CSGOSKINS.GG 对应饰品的官网默认磨损度页面并导入真实历史价。只输入 **蝴蝶刀** 时会显示官网候选，选定具体饰品和磨损度后点“打开网页并读取”。**红宝石蝴蝶刀**等特殊相位也按官网独立页面搜索。也可手动导入 CSV 或官方 API JSON。勾选已导入数据，在右侧填写**买入件数**（默认 1 件），再播放或拖动进度条。
3. 走势金额按“每件历史价格 × 买入件数”计算；结尾显示买入成本、当前总价值和涨跌倍数。可切换显示为 CNY、USD 或 EUR；USD/CNY/EUR 价格会使用最新可用日参考汇率自动换算，汇率及日期显示在币种选择下方。CSV 会按导入时选择的币种记录，演示 CSV 按 CNY 记录。可将走势取点间隔设为**每月**（默认）、**每 3 个月**（自然季度）或**原始数据**。每期取最后一条已有价格，保留起始买入价；缺数据的月份不补点，动画会在相邻数据点间直线过渡。还可调整时间区间、价格口径、归一化、纵轴、比例与导出时长。PNG 按预览画布尺寸保存；视频按所选比例输出，竖屏为 1080×1920。
4. 视频导出会按设定帧率逐帧绘制，再由系统 PATH 中的 `ffmpeg` 合成；没有 ffmpeg 时可用浏览器实时录制 WebM。请保持网页运行至进度结束，然后点击生成的下载链接。

CSV 会存入 `data/skin_reveal.sqlite3`；视频写入 `exports/`。预设也存在同一 SQLite 文件。备份 `data/` 即可保存导入数据和预设。

### 一次性安装 Edge 读取助手

打开 Edge 的 `edge://extensions`，开启“开发人员模式”，点“加载解压缩的扩展”，选择项目中的 `extension` 文件夹。扩展权限只覆盖 `csgoskins.gg/*` 和本机 `127.0.0.1:8765`。已安装旧版时点扩展卡片的“重新加载”。然后在 Edge 打开或刷新 `http://127.0.0.1:8765`。网站如果显示安全检查，需要由你在 Edge 中正常完成，软件会等待页面加载。详见 [extension/README.md](extension/README.md)。无需 csgoskins.gg API key。

中文检索先用项目内的 2,126 条中英饰品名称索引翻译，再由 CSGOSKINS.GG 官网实时搜索确认名称与链接。索引来源为 MIT 许可的 [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API)，许可证保存在 `catalog/LICENSE`；运行 `.venv\Scripts\python.exe update_name_catalog.py` 可更新。常见中文或英文错别字会尝试模糊匹配。站内搜索结果没有完整匹配时只显示候选，不会自动拿相似饰品价格。索引未覆盖的中文别名可能需要输入更常见的名称或英文关键词。

网页图表字段经实测为 `[日期, 最低价（美元美分）, 在售数, 售出数]`，软件仅取日期和最低价，除以 100 后以 USD 保存。它不是中位成交价；切换全局“中位价”时，这种来源仍使用最低价。网站没有覆盖的历史日期不会补造。2026-10-24 在用户 Edge 中核到龙狙页面 2,224 点（2014-07-02 起），红宝石蝴蝶刀崭新出厂页面 573 点（2020-05-29 起）；点数会随网站更新。

## 数据源实测与边界

2026-10-24 运行了 `probe_sources.py`。受限运行环境中的 Python 网络连接被拒绝（WinError 10013）。进一步在可联网进程中请求 csgoskins.gg 的公开红宝石蝴蝶刀页面及历史价 API，均收到 HTTP 403；隔离浏览器停在网站的 Security Check 页面。用户正常打开的 Edge 页面则可展示内嵌 `priceHistory`，因此增加了只读取用户已正常打开页面的本地浏览器助手。它不尝试绕过网站安全检查，也不会把图片曲线估算成价格。

[CSGOSKINS.GG 官方 API 文档](https://csgoskins.gg/docs/)目前列出的历史价地址是 `https://csgoskins.gg/api/v1/price-histories`，需要有效 API key 和付费订阅；Pro 最长 90 天，Business 最长 365 天。返回 `data[].market_hash_name`、`data[].phase`、`dates[].date` 和 `dates[].prices[].price`，价格单位为**美分**。官方说明 `market_hash_name` 只有与 `phase` 组合才唯一；导入 JSON 时会按两者共同筛选，同名多相位而未指定相位时拒绝导入。软件会把多市场价格换算成美元并计算最低价与中位价。需要超过 365 天走势时优先用上述 Edge 页面读取助手，具体时间覆盖范围取决于网站。精确浮点磨损值和图案模板不会从这份汇总历史价中推算。显示币种转换使用 [Frankfurter v2 汇率接口](https://frankfurter.dev/)，读取 USD→CNY/EUR 日参考汇率；接口不可用时沿用本地 12 小时缓存，汇率不属于历史价格数据，切换币种时会用当前最新可用汇率统一换算整条走势。

## 已验证

- 数据核心的 9 个 pytest 用例通过：CSV、官方 JSON 字段结构、中英名称搜索、磨损度与相位、网页历史价导入、降采样与归一化。
- JS 语法检查通过。
- 本地网页可打开，两份演示 CSV 导入后能播放/跳帧；9:16 和 16:9 画布、单件与多件曲线、末尾金额定格均在浏览器检查过。
- 30 秒、24 fps 的竖屏 MP4 已实际导出并用 ffprobe 核对：H.264、1080×1920、720 帧、30.0 秒，文件约 1.5 MB。抽查了中段与结尾画面。
- 双饰品、归一化加对数轴的 GIF 已实际导出并核对：540×960、12 fps、360 帧、30.0 秒，约 1.7 MB。
- 改为按件数计算后，用演示 CSV 核对：龙狙 1 件起始成本 999.07 元、末值 8,577.08 元；2 件分别为 1,998.14 元、17,154.16 元。咆哮 3 件为 2,406.15 元、15,346.08 元。另导出了一份龙狙 2 件加咆哮 3 件的 30 秒竖屏 MP4，核对为 720 帧、24 fps。
- `启动.bat` 已实际启动网页（主页、JS、CSS 和数据接口返回成功）；停止脚本后检查 8765 端口已关闭。
- 输入“红宝石蝴蝶刀”会给出 Ruby 相位、崭新出厂/略有磨损（0.00–0.08）和 StatTrak 选项；网页操作和官方 JSON 多相位隔离已验证。
- 已在 Edge 用“蝴蝶刀传说”和 `★ Butterfly Knife | Lore` 搜索并自动打开官网崭新出厂页，导入 1,849 个历史点；输入“蝴蝶刀”列出 30 个官网候选，从中选 Lore 的略有磨损，导入 1,852 个历史点。曲线分别按月显示 62、63 点。

## 尚未实现

- 无扩展安装的后台直连抓取。网站会拦截程序直连；自动读取需要用户在 Edge 一次性安装助手，并在出现网站安全检查时由用户正常完成。
- 网页独立点价的口径只有 Lowest Price；暂不支持从网页自动生成中位成交价或精确 float/图案种子价格。官方 API 最长只覆盖 365 天，并需要订阅。
- 中文名称索引覆盖 2,126 条饰品；未收录的别名或错别字不保证自动翻译。官网搜索可能出现安全检查、未找到结果或暂时不可用。
- 严格小于 20 MB 的视频体积保证；实际大小取决于数据、比例、时长和编码效果。

运行测试：`.venv\Scripts\python.exe -m pytest -q --basetemp=.\.tmp\pytest_run`。重新检测官方网络连通性：`.venv\Scripts\python.exe probe_sources.py`。
