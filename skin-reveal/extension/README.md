# Edge 读取助手

本扩展只在带有 Skin Reveal 一次性任务编号的 `csgoskins.gg` 搜索页读取官网候选名称和链接，或在饰品页读取已经展示的 `priceHistory` 数组，并发送到本机 `127.0.0.1:8765`。不读取密码、Cookie 或其他网站。

一次性安装：打开 Edge 的 `edge://extensions`，开启“开发人员模式”，点“加载解压缩的扩展”，选择本目录 `D:\Download\cs走势图表制作\extension`。安装后刷新 Skin Reveal 网页。已安装旧版时点扩展卡片的“重新加载”，再刷新软件页面。扩展权限包括 `csgoskins.gg/*` 和本机 `127.0.0.1:8765`，因为搜索页在网站首页。

以后在 Skin Reveal 输入中文或英文饰品名，点“联网搜索并读取”。完整匹配会自动进入该饰品的官网规格页并导入历史价；不完整名称先列出候选，可选磨损度后读取。新页面若遇网站安全检查，请由你在 Edge 中正常完成；网站页面没有有效数据时不会生成价格。
